## 4. 🔴 The class is 1,807 units, not the ~13,778 the ruling scoped

Measured with the shipped classifier on the 714-project corpus (572,997 units):

| class | units | share | status |
|---|---|---|---|
| **inert** | **1,807** | **0.32%** | the entire scope of this change |
| changelog | 40,047 | 6.99% | 🔒 untouched, permanently |
| readme | 12,492 | 2.18% | 🔒 untouched, permanently |
| ordinary | 518,651 | 90.52% | — |

**The pre-registration's `~13,778` was arithmetic, and the arithmetic double-counted.** It was
`51,410 − 37,632` — *"front matter that is not a CHANGELOG"* — which **includes every README**, and
README was then listed on its own row at ~11,268. The number never described the inert class.
**The real scope is 7.6× smaller than the ruling was given**, and the ruling's intent (demote only
the inert class) is satisfied more narrowly than it was written, not more widely.

⭐ **This is why the fire rate is 2.6%**, and it was knowable before the run. It is recorded here
because §4's bar was set against a population that did not exist.

## 5. 🔴 A DEFECT IN THE FIRST DRAFT: the classifier swept in CODE files

The first classifier matched on basename alone and classified **126 source files** as inert:

| file | units |
|---|---|
| `Governance.t.sol` | 42 |
| `governance.rs` | 41 |
| `governance.ts` | 28 |
| `Governance.sol` | 8 |
| `License.sol` | 6 |
| `security.rs` | 1 |

**Demoting `Governance.sol` demotes an actual governance contract** — the ranking answer to a
governance question, buried by a rule written about front matter. **D15's shape**: one domain's
vocabulary silently labelling another.

**Fixed** with a prose-extension guard (`''` · `md` · `mdx` · `markdown` · `rst` · `txt` · `adoc` ·
`asciidoc`): a `.sol`, `.rs` or `.ts` file is source, whatever it is called. **Caught by printing
the basenames the classifier had matched** rather than only its count — a count of 1,933 looks
exactly like a count of 1,807.

is bound by the argument.
