## 2. The measurement, with composition

**Simulated 12-call session** over the two demo tasks and the OZ question, batches of 5 selectors
(the registered cap), selectors taken from what `search` actually returns — **not hand-picked**,
because choosing the input data is the one thing a measurement must never let the measurer do.

| | OFF | ON | saved |
|---|---|---|---|
| per-call total | 17,774 | 16,082 | **9.5%** |
| **cumulative** (every prior result re-sent each turn) | 115,715 | 110,262 | **4.7%** |

| composition | |
|---|---|
| bodies deduped | **13** |
| 🔴 repeats **refused** — ref not strictly smaller | **14** |
| calls where the arm fired at all | **5 of 12** |

⭐ **The refusal count is the finding, and it is larger than the win.** More than half of the
repeat opportunities could not be taken because the self-describing ref (~330 characters) is not
smaller than the body it would replace. The bodies in these payloads are short.

🔴 **The obvious lever is forbidden here.** Shortening the ref would raise the number, and the
ref's self-description — hash, selector, size, the route back, the statement that citations are
never dropped — is a **ruled constraint**. **Shortening it after seeing the number to clear a bar
is F22**, and the bar was written down first precisely so that move would be visible. Recorded as a
question for the owner, not taken.

⚠ **The cumulative model is the worst case**: it assumes every prior tool result is re-sent on
every turn. That is what M-B observed, and it is the term C2 targets, but a client that prunes its
own transcript would see less.

## 3. Two defects in the build, both caught by running it

🔴 **The dedupe arm was LARGER than the control on every call where nothing repeated.** The report
object (`{deduped, bytesSaved, remembered, refusedNotSmaller}`) was emitted unconditionally —
**+21 tokens per call, to say that nothing happened.** C2's own rule, *a ref must be strictly
smaller than what it replaces or it does not fire*, applied to everything except C2's own
bookkeeping. The report is now emitted only when something was actually deduped. **Before the fix
the per-call arm read 12,775 → 12,419 with five calls going the wrong way; after it, 17,774 →
16,082 with none.**

⚠ **The session ran 9 calls, not the 12 the pre-statement fixed.** The corpus yields 6 first-pass
batches and my re-fetch loop added 3. Extended to 12 as registered — **honouring the
pre-registration, not tuning the length**, and stated here because the difference is visible in the
numbers.

## 4. 🔴 THE FACT THAT DECIDES C2'S FUTURE, established before the build

**The deployed server issues no session id.** Probed: `initialize` on `/mcp` returns **no
`mcp-session-id` response header** — the header appears in the CORS allow-list and is never sent.

**Under C2's own scope constraint — *no session id → no dedupe* — C2 cannot fire on the deployed
transport at all**, whatever E1 had said. Establishing that *before* building is the difference
between a measured failure and an unmeasured one.

⚠ **The session key does not trust the client alone.** An `Mcp-Session-Id` sent by a caller is
caller-controlled, so two callers could send the same value and one would receive a ref for a body
the other received — the constraint's forbidden case exactly. It is bound to **the caller identity
the limiter already establishes** (GitHub user id on the elevated route, IP on the authless one),
so a collision requires the same caller. **Both halves are required; either missing means no
dedupe**, asserted by test.

## 5. Falsifications — four, each shown to land (R4)

| break | observed |
|---|---|
| remove the session-id guard | G3 fails, alone |
| remove the strictly-smaller check | G4 + the report test fail |
| key on the **selector** instead of the content | 3 tests fail, including the two-selectors-one-body case |
| drop provenance on a deduped unit | G1 fails, alone |
| corrupt a ref (a hash never remembered) | the **full body** is served — there is no state in which a ref points at nothing |

**661 tests pass.** Shakedown ✔ **GREEN 10/10**, anchor `vs last run: UNCHANGED` — nothing shipped,
so nothing moved.

## 6. What ships

**Nothing.** `packages/mcp-server/src/dedupe.ts`, its ten tests and
`tools/measure-c2-dedupe.ts` are kept so the result is re-runnable at $0 on any future corpus.
`apps/mcp` never constructs a store, so the field is `undefined` on every deployed request and the
payload is byte-identical to before C2 existed.

🔴 **A full M-B re-run is NOT part of this and the agent-loop effect stays UNMEASURED.** It needs an

reason not to spend the money on C2 alone.
